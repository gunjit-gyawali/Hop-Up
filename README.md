# Hop Up

hey! welcome to **Hop Up**, a little game I made in Godot inspired by the OG Doodle Jump!

The goal is pretty simple: keep hopping up, get a higher score, and see how far you can go. Sounds easy, right? well, let's see how long you can survive before things get tricky.

I made this project to try making my own game and have some fun with game development. It's a simple concept, but making it work was a fun experience!

## How to Play

- Use the **arrow keys** to change your direction.
- Keep moving and try to get as high as possible.
- Score points as you progress, just like in the original Doodle Jump.
- Try to beat your high score and challenge yourself to go even further!

## Features

- Simple and fun gameplay.
- Endless jumping vibes inspired by Doodle Jump.
- A scoring system inspired by the original game.
- Arrow key controls to change direction.
- Made with Godot!

## Built With

- **Godot Engine** — for making the game.
- **GDScript** — used for the game's scripts.

## How to Run

Visit - https://gunjitgyawali1.itch.io/hop-up

OR

Want to see source code and play the game yourself locally? Here's how:

1. Download or clone this repository.
2. Open the Godot Engine.
3. Click **Import** and select the game's `project.godot` file.
4. Open the project.
5. Press **F6** to run the current scene or **F5** to run the main project.

And that's it! You're ready to play.
