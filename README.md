# Hop Up

 This game is inspired by the original Doodle Jump game. The core concept is the same as og game: you have to keep going up as high as possible, get your high score, and try to beat your high score in the next game.

## How to Play

- Use the **arrow keys or A/D** to change direction.
- Try to get as high as possible.
- Score points as you progress, like in the original Doodle Jump.
- Try to beat your high score!

## Features

- Simple and fun gameplay.
- Endless jumping inspired by Doodle Jump.
- A scoring system inspired by the original game.
- Arrow keys or A/D controls to change direction.
- Made with Godot!

## Built With

- **Godot Engine** — making the game.
- **GDScript** — for the game's scripts.

## How to Run

Visit - https://gunjitgyawali1.itch.io/hop-up

OR

1. Download or clone this repository.
2. Open the Godot Engine.
3. Click **Import** and select the game's `project.godot` file.
4. Open the project.
5. Press **F6** to run the current scene or **F5** to run the main project.
